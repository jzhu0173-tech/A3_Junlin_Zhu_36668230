# ElderLink A2

This is a Vue 3 + Vite web application prototype for FIT5032 A2.

Core business requirements covered in the app:

- `BR A.1`: Built with Vue 3 and reactive state.
- `BR A.2`: Responsive layout for mobile, tablet, desktop, and very wide screens.
- `BR B.1`: Input validation for required fields, email, phone, password, rating range, and message length.
- `BR B.2`: Dynamic services, activities, requests, users, and ratings driven by JavaScript data structures and local storage.
- `BR C.1`: Registration and login using multiple local users.
- `BR C.2`: Role-based access with resident/carer and coordinator roles.
- `BR C.3`: Rating system with aggregate scores.
- `BR C.4`: Basic security via input sanitisation, validation before storage, and no client-side secrets.
